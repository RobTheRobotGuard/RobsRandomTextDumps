# Supported Mods

Every mod this addon adds `MayRequire`-gated rewards for. None of this addon's content loads unless at least one of these mods is also active -- by design, per Winston Wave's own `MayRequire` convention, so this addon never errors or does anything on a modlist that has none of these installed.
